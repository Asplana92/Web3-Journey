## 1️⃣ Pre-Launch Preparation (Before November 24)

### 🔐 1. Wallet Security

- [ ] MetaMask updated to the latest version
- [ ] Seed phrase written on paper (NOT digital!)
- [ ] Backups stored in at least two secure physical locations
- [ ] Seed phrase recovery tested (restore into a fresh MetaMask profile)
- [ ] Hardware wallet prepared (recommended for large holdings)

> 🚨 **Critical:** Never store seed phrases digitally (screenshots, photos, cloud, password managers).

---

### 🌐 2. Network Configuration

- [ ] Mainnet network details bookmarked (RPC, Explorer — to be announced)
- [ ] Monad official sources saved:

| 💬 Discord | https://discord.com/invite/monad |

### 💰 3. Funding & Bridging Preparation

- [ ] ETH available for bridging ($50–100 recommended)
- [ ] Await official bridge announcement (do not use alternatives)
- [ ] Understand basic bridging flow (deposit → confirmation → receive)
- [ ] Plan a small-value first transfer (safety first)

> 🛡️ **Safety:** Double-check URLs. Use only links from official sources.

---

### 💻 4. Device & Browser Setup

- [ ] Browser cache cleared
- [ ] MetaMask running smoothly
- [ ] Stable desktop/laptop connection (avoid mobile-only setup)
- [ ] VPN disabled if causing RPC issues

---

### 📖 5. Knowledge Preparation

- [ ] Read new mainnet documentation (once published)
- [ ] Understand gas model and transaction fee structure
- [ ] Practice on Testnet (explorer, simple transactions)
- [ ] Know where to ask for help (Discord)

## 2️⃣ Launch Day Strategy (November 24)

### ⏰ First 15 Minutes

- [ ] Check official announcement that mainnet is live
- [ ] Add mainnet RPC to MetaMask (official parameters only)
- [ ] Confirm RPC connectivity (block height must increase)
- [ ] Avoid rushing — network may be busy

---

### ⏱️ First Hour

- [ ] Bridge a small test amount (e.g., $10–20)
- [ ] Wait for confirmation (may take 10–30min)
- [ ] Verify the transaction on block explorer
- [ ] Make a small self-transfer
- [ ] Take screenshots for personal records

---

### 🕐 First 6 Hours

- [ ] Interact with initial ecosystem dApps (if launched)
- [ ] Compare RPC performance
- [ ] Monitor gas prices
- [ ] Document any unexpected behavior
- [ ] Share helpful feedback in Discord

---

### 📅 First 24 Hours

- [ ] Explore multiple dApps
- [ ] Participate in early ecosystem activities
- [ ] File any bug reports found
- [ ] Share your onboarding experience publicly (Twitter/Discord)

## 3️⃣ Troubleshooting Guide

### ❌ Transaction Fails

**Possible causes:**
- Low gas
- Network congestion
- Incorrect nonce

**Fixes:**
1. Increase gas
2. Wait and retry
3. Reset MetaMask account
4. Clear pending transactions

---

### 🔌 RPC Not Responding

**Possible causes:**
- High traffic
- Overloaded RPC endpoint
- Browser issues

**Fixes:**
1. Switch to alternative RPC (if provided)
2. Reload browser
3. Wait a few minutes
4. Check Discord for status updates

---

### 🌉 Bridge Delays

**Possible causes:**
- Congestion
- Cross-chain confirmation lag

**Fixes:**
1. Wait 30–60 minutes
2. Verify source-chain transaction
3. Check official status pages
4. Ask in https://discord.com/invite/monad

---

### 👻 Tokens Not Visible

**Possible causes:**
- Token not added
- Wrong network

**Fixes:**
1. Verify network selection
2. Add token via contract address
3. Confirm balance on block explorer
